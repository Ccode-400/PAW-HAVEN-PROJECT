# 🐾 PAW HAVEN PROJECT

> A modern pet adoption and rescue platform dedicated to helping rescued cats and dogs find loving homes while connecting volunteers with animal rescue services.

---

## 📖 Overview

PAW HAVEN PROJECT is a web-based pet adoption platform built to bridge the gap between rescued animals and compassionate adopters. The platform allows users to:

* Browse pets available for adoption
* Learn more about rescued animals
* Volunteer in animal rescue services
* Support pet welfare initiatives
* Provide rescued pets with a second chance at a loving home

The project is developed using modern frontend technologies with a fast and optimized development workflow powered by Vite and React.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js (v18 or later recommended)
* npm
* Git

---

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Ccode-400/PAW-HAVEN-PROJECT.git
```

### 2. Navigate into the project directory

```bash
cd PAW-HAVEN-PROJECT
```

### 3. Install dependencies

```bash
npm install
```

---

## ▶️ Running the Project

### Start the development server

```bash
npm run dev
```

The application will run locally on:

```bash
http://localhost:5173
```

---

## 🗄 Running the Mock Database

This project includes a `db.json` file that can be used with JSON Server for mock backend functionality.

### Install JSON Server globally

```bash
npm install -g json-server
```

### Start the mock API server

```bash
json-server --watch db.json --port 3000
```

Mock API endpoint:

```bash
http://localhost:3000
```
